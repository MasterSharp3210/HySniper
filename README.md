# HySniper
HySniper Bot to snipe player stats of Hypixel Bedwars

# How to use
To use the bot, you need to follow steps here:
- **First Step**: Register a Minecraft account with your Hypixel profile on this page: *https://hypixel.net/login*.

- **Second Step**: Go to *https://developer.hypixel.net* and login with your Hypixel profile.

- **Third Step**: Generate an Hypixel API key and copy that.

- **Quarter Step**: Open the HySniper.py file and paste the API key in the specific API line.

- **Fifth Step**: Go to your Discord server and generate a webhook. *Follow tutorial here: https://support.discord.com/hc/en-us/articles/228383668-Intro-to-Webhooks*

- **Sixth Step**: Copy the Webhook URL into the specific URL line in HySniper.py

- After this, in the Player line write the name of player you want to track. Then save and start the bot.
